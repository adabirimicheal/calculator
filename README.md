# Calculator App

A simple web-based calculator built with **HTML, CSS, and JavaScript**.

## Project Structure

```text
calculator/
├── index.html   # Calculator layout and buttons
├── style.css    # Appearance, layout, and responsive styling
└── script.js    # Calculator behavior and calculations
```

## Features

- Calculator interface displayed in the browser
- HTML for the page structure
- CSS for the design and layout
- JavaScript for button interactions and calculation logic

> The exact operations and extra features depend on what is implemented in `script.js`.

## How to Run

1. Download or extract the project folder.
2. Keep `index.html`, `style.css`, and `script.js` together in the same folder.
3. Open `index.html` in a web browser such as Chrome, Edge, or Firefox.
4. Use the calculator buttons to perform calculations.

No package installation or build step is required for a basic HTML/CSS/JavaScript project.

## Editing the Project

- **Change the interface:** edit `index.html`.
- **Change colors, spacing, or styling:** edit `style.css`.
- **Change calculator behavior:** edit `script.js`.

A code editor such as Visual Studio Code is recommended.

## Troubleshooting

- If the design does not appear, check that `style.css` is linked correctly in `index.html`.
- If the buttons do not work, check that `script.js` is linked correctly and inspect the browser console for JavaScript errors.
- Make sure the three main files remain in the same folder unless you update their paths in the HTML.
